# docs/

Quarto book for the rz-frida plugin. From this directory:

```bash
$ quarto preview
$ quarto render .
```

Chapter files are `.qmd` (required for mermaid). HTML mermaid is configured in
`_quarto.yml` under `format.html.mermaid`. Figures are in `img/`.

Prose is CC-BY-4.0. Example code under `examples/` is LGPL-3.0-only.

The generated `_book/` and `.quarto/` trees are gitignored.
